# Media assets

Place original media here before rendering a real edit.

Suggested structure:
- `assets/video/` — source gameplay and camera clips
- `assets/audio/voice/` — original narration stem
- `assets/audio/sfx/` — sound effects
- `assets/images/` — screenshots, memes, logos and sourced stills
- `assets/fonts/` — licensed fonts

Keep filenames short and numbered in intended editorial order (for example `clip-01.mp4`). Keep a source/rights note for downloaded material. Do not commit very large media files to Git if they can be transferred directly to the render workspace instead.
