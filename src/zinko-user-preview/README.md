# ZINKO GTA VI — 15-second preview

This branch contains an isolated Remotion composition for the creator's requested first 15 seconds.

- 00:00–00:10: Scene 1 from the supplied 18-scene pack.
- 00:10–00:15: First five seconds of Scene 2.
- Original voice stems 1 and 2, with stem 2 trimmed naturally by the composition endpoint.
- Official Rockstar gameplay cutaways from the repository's sourced GTA VI media assets.
- User-provided sound effects; no background music.
- 1920×1080, 30 fps, H.264/AAC.

The full 18-scene source pack is not committed to Git. The workflow downloads only the two clips, two voice stems, and seven sound effects needed for the preview from the creator's Drive folder at render time.
