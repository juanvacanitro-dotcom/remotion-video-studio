# remotion-video-studio

## GTA 6 R8 intro preview

A 30-second, 16:9 Remotion composition built from the first three scenes of the supplied GTA 6 script. It uses the Zinko direction: energetic Nico cutout, oversized yellow/white kinetic typography, neon transitions, illustrated gamer-room and neon-city layers, and subtitles. It intentionally contains no background music, in line with the supplied script.

Open Remotion Studio and choose `GTA6R8Intro`, or render with:

```bash
npm run render:r8
```

The R8 composition is a visual edit preview. The original narration track from R7 was not available in the current Drive folder at build time, so no replacement voice or music is fabricated. Add the original voice recording as a separate audio track before treating this as the final publishable cut.
