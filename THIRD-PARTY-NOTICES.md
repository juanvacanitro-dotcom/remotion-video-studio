# Third-party notices — ZINKO motion graphics

The project at https://github.com/echris6/gta-components was reviewed as a motion-design reference.

Its README describes 126 GTA-video motion-graphics components built as standalone HyperFrames HTML projects using GSAP and Three.js. It is not a Remotion/React component package, and it does not include gameplay footage. Its code is MIT-licensed; fonts under shared/fonts retain their SIL Open Font License 1.1 notices.

Rather than adding a second rendering stack or copying the full repository, this project uses a small Remotion-native motion kit inspired by the documented patterns: kinetic word captions, punch-in movement, impact transitions, presenter-avatar cut-ins, and a metallic title sting. The new components are authored for this project's existing Remotion 4 composition and use the project's own mascot assets.

Original reference: https://github.com/echris6/gta-components
